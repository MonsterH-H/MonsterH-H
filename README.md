### HESYD-ONE : agent documentaire d'archives multi-tenant

<img src="https://img.shields.io/badge/Cat%C3%A9gorie-IA-0F766E?style=flat-square" alt="IA"/> <img src="https://img.shields.io/badge/Statut-Complet-0F766E?style=flat-square" alt="Complet"/> <img src="https://img.shields.io/badge/Code-Public-0369A1?style=flat-square" alt="Public"/> <img src="https://img.shields.io/badge/Maturit%C3%A9-L4-334155?style=flat-square" alt="L4"/>

| | |
|:--|:--|
| **Problème** | Les organisations reçoivent leurs documents par e-mail, WhatsApp et Drive, sans classification ni preuve de dépôt. L'archivage devient opaque et les questions sur les données restent sans réponse sourcée. |
| **Solution** | Un SaaS multi-tenant qui industrialise tout le cycle documentaire, de la réception à la livraison, avec un agent IA dont chaque réponse cite ses sources. |
| **Chaîne de traitement** | Réception multicanal → Classification → Archivage sur preuve (SHA-256 revérifié) → Questions-réponses sourcées → Livrables PDF, Excel, Word |
| **Résultats** | • 63 routes API réparties en 31 domaines<br/>• 39 modèles Prisma, 36 modules `lib/`<br/>• 14 outils d'agent IA typés<br/>• 185 fichiers TS/TSX, environ 30 900 lignes<br/>• MFA TOTP (RFC 6238), Google OAuth 2.0 avec PKCE (S256), webhooks Polar vérifiés en `timingSafeEqual`<br/>• Test d'isolation inter-organisations exécuté (documenté dans `docs/AUDIT.md`) |
| **Stack** | `Next.js 16` `React 19` `Prisma 6` `SQLite (dev)` `PostgreSQL + pgvector (prod)` `z-ai-web-dev-sdk` `Azure AI Foundry` `Google Document AI` `Polar` `WhatsApp Cloud API` `n8n` `Docker` |
| **État** | Complet. Déploiement VPS documenté dans `docs/DEPLOIEMENT.md` (RPO 24 h, RTO 8 h). |
| **Preuve** | [Dépôt GitHub](https://github.com/MonsterH-H/HESYD-ONE) · [Portfolio](https://handytsoka.vercel.app/) |

### Valify : SaaS de réservation sécurisé par engagement financier

<img src="https://img.shields.io/badge/Cat%C3%A9gorie-Full%20Stack-BE185D?style=flat-square" alt="Full Stack"/> <img src="https://img.shields.io/badge/Statut-Complet-0F766E?style=flat-square" alt="Complet"/> <img src="https://img.shields.io/badge/Code-Priv%C3%A9-475569?style=flat-square" alt="Privé"/> <img src="https://img.shields.io/badge/Maturit%C3%A9-L4-334155?style=flat-square" alt="L4"/>

| **Solution** | Une plateforme multi-tenant de réservation en ligne où chaque créneau est validé par un acompte ou une empreinte bancaire. Tunnel de réservation sans compte client, pénalités configurables, litiges et remboursements tracés, espace client sans mot de passe. |

| **Stack** | `Next.js 16` `TypeScript strict` `Prisma 6` `PostgreSQL (Neon)` `Polar (webhooks Svix signés)` `Resend` `WhatsApp` `Web Push VAPID` `Bun` `Playwright` |

### AIDIP : BI conversationnelle pour Microsoft Fabric

<img src="https://img.shields.io/badge/Cat%C3%A9gorie-IA-0F766E?style=flat-square" alt="IA"/> <img src="https://img.shields.io/badge/Statut-Complet-0F766E?style=flat-square" alt="Complet"/> <img src="https://img.shields.io/badge/Code-Public%20(v3)-0369A1?style=flat-square" alt="Public v3"/> <img src="https://img.shields.io/badge/Maturit%C3%A9-L4-334155?style=flat-square" alt="L4"/>

| | |
|:--|:--|
| **Problème** | Les utilisateurs métier ne savent pas écrire le DAX nécessaire pour interroger les modèles sémantiques Power BI, et les LLM « inventent » des chiffres lorsqu'ils ne sont pas contraints. |
| **Solution** | Une plateforme d'analytique conversationnelle. L'utilisateur pose sa question en langage naturel, un pipeline planifie la requête DAX, l'exécute sur le modèle sémantique réel, interprète les résultats sans droit d'inventer, puis valide chaque affirmation contre les preuves. Le score de confiance est calculé de façon déterministe, pas deviné par le LLM. |
| **Chaîne de traitement** | Question en langage naturel → Plan DAX → Exécution sur Fabric → Interprétation → Validation anti-hallucination → Export PDF, PowerPoint éditable, CSV |
| **Résultats v3 (publique)** | • 183 fichiers, environ 36 500 lignes, 23 pages, 64 composants<br/>• 14 entités sous RLS, 13 UDFs côté serveur<br/>• Pipeline NL vers DAX en 7 étapes avec garde-fou anti-hallucination |
| **Résultats v4 (privée)** | • 18 modèles Prisma, pipeline en 4 étapes (plan, exécution multi-DAX, interprétation, validation)<br/>• Module d'administration de 7 pages<br/>• Exports PDF (sommaire, pagination), PPTX natif éditable, CSV RFC 4180<br/>• Authentification Microsoft Entra ID (NextAuth), adaptateur de démo Contoso en mémoire<br/>• Moteur de graphes SVG sur mesure, sans librairie lourde |
| **Stack** | `React` `Azure OpenAI` `Fabric SQL` `RLS` `NextAuth` `pdf-lib` |
| **Code** | [Dépôt de la v3 (public)](https://github.com/MonsterH-H/aidip-generator) · la v4 est complète mais confidentielle |
